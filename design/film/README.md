# Film

Greg's 35mm frames live in `public/images/film/` (web-ready, ≤ 2400px), kept as texture, depth and film-study reference.

In use: the hero's column 5 flips through the roll as the pointer moves across the window, from a random first frame (`app/components/ui/film-frame.tsx`, which lists each frame with its alt text; 800px copies in `800/`). Add a frame there, and its 800px copy, to put it in rotation.
