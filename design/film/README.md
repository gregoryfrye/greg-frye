# Film

Greg's 35mm frames live in `public/images/film/` (web-ready, ≤ 2400px), kept as texture, depth and film-study reference.

In use: the hero's column 5 flips through the roll as the pointer moves across the page (`app/components/ui/film-frame.tsx`, which lists each frame with its alt text; it shows the 720px copies in `sm/`). To add a frame: put the full JPEG here and a 720px copy in `sm/`, then add it to the list.
