**Stack.** Next.js and Tailwind on Vercel. Notion is the CMS, so the studio edits the site where it already works. Media lives in Vercel Blob. Every change ships to a staging branch before production.

**Mark pipeline.** A small local tool traces masked artwork into SVG marks, with sliders for each parameter, so the identity's mark expressions come out of the same system as the site.
